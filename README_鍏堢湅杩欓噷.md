# v54 手机适配与原文小标题导图版

本版本不新增卡片，仍为250张。

## 核心修复

1. 手机端不再把“导图”和“详情”上下堆叠。点击任意原文小标题或卡片后，会打开全屏详情；点击“返回导图”继续查看。
2. 大型导图节点改为文档原思维导图中的小标题，不再仅按系统卡片分类机械生成。
3. 原文小标题下挂对应知识点、课堂笔记、题目和PDF，点击卡片可进入原卡片。
4. 电脑端仍保留左侧大型导图与右侧内容预览。

上传仓库时完整覆盖旧文件，尤其不要遗漏：mindmap.html、mindmap.css、mindmap.js、mindmap-data.js、sw.js。
发布完成后电脑按 Ctrl+F5；手机关闭旧网页后重新打开。
