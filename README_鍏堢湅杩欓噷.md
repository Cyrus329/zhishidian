# 重要：这是零起点全清空版

首次打开任意页面时，会自动清除以前的已看、掌握、错题、作答、复习排期、学习时长、错因和每日计划，然后从零开始。知识卡、题目、课堂笔记和原始资料不会删除。

清理只执行一次；开始学习后刷新页面不会再次清空。

# v56 全优先级高效记忆版

本版本没有新增或删除知识卡，仍保留250张内容。背诵中心新增自适应复习、白纸回忆、语音复述、一题多练、对比卡、章节闯关、混合复习、错因统计、睡前/次日回顾和周报告。

首页和卡片列表会用红色“今日复习”和橙色“今日必背”进行强提醒。每日默认安排20个新知识点，可在背诵中心修改。

本压缩包会保留原学习记录。另有“零起点版”会在首次打开时清空旧存档，请勿混用。

# v55 背诵中心与课堂笔记分离版

本版本不新增卡片，也不新增导入日期，原有250张卡片和学习记录ID均保持不变。

## 新增入口

- `memory.html`：背诵中心。包含今日队列、章节主动回忆、关键词漏点检测和薄弱知识导图。
- `notes.html`：课堂笔记中心。课堂笔记单独显示，并标注学科、章、节、知识块、机构和导入日期。
- `mindmap.html`：背诵思维导图。只显示需要背诵的知识点和题目，不再混入课堂笔记。

## 上传要求

完整覆盖仓库，尤其不要漏掉：

- memory.html / memory.css / memory.js
- notes.html / notes.css / notes.js
- mindmap.html / mindmap.css / mindmap.js / mindmap-data.js
- index.html / styles.css / app.js / sw.js

发布后电脑按 `Ctrl + F5`，手机关闭旧页面后重新打开。
