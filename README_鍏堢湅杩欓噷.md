## 使用方法

1. 将压缩包内全部文件和文件夹完整覆盖到GitHub仓库根目录。
2. 不要遗漏 `imports` 文件夹。
3. GitHub Pages更新后按一次 `Ctrl + F5`。
4. 手机端仍显示旧版时，关闭网页后重新打开；安装成应用的版本可退出后再次打开。
