# v53 大型思维导图联动版

本版基于 v52，不新增学习日期、不改变250张卡片的ID和学习记录，新增“方案B：左侧大型导图 + 右侧内容预览”。

## 新增功能

- 新增独立页面 `mindmap.html`，主页顶部和原章节导图区域都可以进入。
- 左侧按“原文档标题 → 知识分类 → 对应卡片”展示大型可展开导图。
- 右侧显示所选文档标题、知识点、课堂笔记、题目或PDF资料的详细预览。
- 点击知识点节点后，可直接进入原卡片；也可在新窗口打开。
- 支持学科、机构来源、内容类型和关键词筛选。
- 支持展开全部、收起全部、回到顶部。
- 知识点、课堂笔记、题目和PDF采用不同标记。

## 文档标题结构

计算机第一章按全方位文档标题组织：

- 01-阿兰·图灵
- 02-冯·诺依曼
- 03-著名计算机
- 04-发展阶段
- 05-计算机的特点
- 06-计算机的分类
- 07-计算机的应用
- 08-计算机的未来
- 09-计算思维
- 10-计算机文化

其中09和10保留原PDF提纲与原PDF入口；当前没有对应卡片的节点会显示“后续导入时自动挂入”，不会伪造背诵卡。

英语和数学按现有上传讲义标题组织，内部再展开知识点、课堂笔记和题目。

## 数据说明

- 总卡片仍为250张。
- 学习记录继续使用原存储键，不会因升级丢失。
- 课堂笔记仍不参与填空、掌握率和抗遗忘。
- 本版只增加导航和预览，不把09、10资料擅自改成知识点背诵卡。

## 上传方法

完整覆盖GitHub仓库中的旧文件和文件夹。不要遗漏：

- `mindmap.html`
- `mindmap.css`
- `mindmap.js`
- `mindmap-data.js`
- `imports/reference-mindmaps`

发布后电脑按一次 Ctrl+F5；手机端关闭旧网页后重新打开。
